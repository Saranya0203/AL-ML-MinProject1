# NYC 311 Complaint Analysis Dashboard

## Project Overview
An interactive dashboard to analyze NYC 311 service requests using Python, PostgreSQL and Streamlit.

## Technologies Used
- Python
- numpy
- Pandas
- PostgreSQL 17
- SQLAlchemy
- Streamlit
- Plotly

## Dashboard Features
- Total service requests
- Complaint distribution by borough
- Top complaint types
- Monthly complaint trends
- Resolution time analysis
- Interactive filters

## How to Run

Install dependencies:

    !pip install -r Requirementlibrary.txt

Run the dashboard:

    streamlit run nyc_dashboard.py

## Database
PostgreSQL database: urban_pulse_db

Table: service_requests
